# Ver. Zero Project — bilingual GitHub Pages

Upload `index.html` and `index-zh-TW.html` to the repository root. Both pages contain embedded images, styles, and JavaScript.

The IPS download buttons link to the Anode v1a and Cathode v1c GitHub Releases provided by the project maintainer. Previous Anode v1.0A hashes are retained as historical README data, not verified against the new release downloads.


## Patch section update
Both language pages include Anode v1a and Cathode v1c download links, filenames, SHA-256 values supplied by the project, and TBC placeholders for unknown Cathode ROM hashes.
