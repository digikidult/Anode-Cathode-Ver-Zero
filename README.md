# Ver. Zero Project — Self-contained GitHub Pages

Both HTML files include their own images, CSS and JavaScript. No assets directory is required.

Upload `index.html` and `index-zh-TW.html` to the **root** of your GitHub repository. In Settings > Pages, deploy from main / (root).

Open index.html locally to verify the pictures, and click EN / 繁體中文 to switch languages.

Source: Digikidult project README v1.0A. Free, non-commercial fan project.
