1. 關於本企劃 / About This Project

斯路再現計劃 (Ver. Zero Project) 是一項基於 Bandai WonderSwan 遊戲《Digimon Adventure: Anode Tamer》製作的非官方粉絲項目[cite: 1, 2]。本企劃旨在讓昔日活動限定的數碼暴龍「V龍獸 (ブイドラモン)」再次登場，讓玩家能透過遊戲流程入手，同時加入可習得的限定合體技能之方式[cite: 1, 2]。

2. 升級版內容 / Features

V龍獸 — 遊戲通關獎勵 (Game Completion Reward)

當玩家完成主線故事的最後迷宮（擊敗千年獸）後，V龍獸便會作為通關獎勵，於 Server Room 分子獸可領取的數碼暴龍名單之中[cite: 1, 2]。

遊戲平衡性考量: 經過諮詢香港及日本資深數碼暴龍玩家的意見，並考慮 V龍獸在遊戲中的數值後，決定採用與英文版不同的入手方式，以維持遊戲平衡性並帶來更具成就感的體驗[cite: 1, 2]。

限定合體技能之學習方式 (Variable Moves)

讓 V龍獸與另一隻指定數碼暴龍一同作戰，便有機會習得以下限定合體技能[cite: 1, 2]：

合體技能 (Variable Move) 所需數碼暴龍組合 (Required Combination)
奧米加獸 (Omegamon) V龍獸 + 亞古獸 / ？[cite: 1, 2]
神龍獸 (Goddramon) V龍獸 + ？[cite: 1, 2]

安裝步驟 (Installation Steps)

  1. 從您的 WonderSwan 遊戲卡帶中備份《Digimon Adventure: Anode Tamer》（請檢查是否為 Rev.1 版本）的原始 ROM[cite: 1, 2]。
  2. 使用支援 IPS 格式的補丁工具，將提供的 IPS 補丁套用至原始 ROM[cite: 1, 2]。
  3. 使用 WonderSwan 模擬器或相容的實體硬件運行修改後的遊戲[cite: 1, 2]。
⚠️ Distribution Notice: 本項目僅提供 IPS 補丁檔案，絕不提供原版遊戲 ROM 或已修改的完整 ROM[cite: 1, 2]。
