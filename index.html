01 / About the Project

Ver. Zero Project is an unofficial, fan-made modification of Digimon Adventure: Anode Tamer for Bandai WonderSwan. It revives the event-exclusive Veedramon as an obtainable in-game reward and introduces additional learnable special moves (Variable Moves).

Original gameDigimon Adventure: Anode Tamer (Japanese Rev.1)
Project managerDigikidult
Project statusCompleted
DistributionFree, non-commercial fan project

02 / Features

Veedramon — Game Completion Reward

After clearing the final story dungeon, one Veedramon will be added to the list of Digimon available to receive from the Server Room.

Game Balance Considerations

After consulting experienced Digimon players from Hong Kong and Japan and considering Veedramon’s in-game stats, the team chose an acquisition method different from the English version. This preserves the original challenge while offering a rewarding new experience.

Additional Learnable Variable Moves

Let Veedramon fight alongside a specified Digimon to have a chance to learn these moves. Question marks are intentionally retained from the project documentation.

Variable MoveRequired Digimon Combination

Installation

  1. Dump the original Japanese Anode Tamer Rev.1 ROM from your own WonderSwan cartridge.
  2. Apply the IPS patch to the original ROM using an IPS-compatible patching tool.
  3. Play on a WonderSwan emulator or compatible physical hardware.

Distribution notice: Only the IPS patch is distributed. No original or pre-patched game ROM is provided.
